# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone. Maintainers may remove comments, commits or contributors that break these rules.

Report unacceptable behavior privately to the maintainer through the contact options on the [maintainer's GitHub profile](https://github.com/mucahitimre). Reports are handled confidentially.
